# Runtime assets digest (SBOM baseline)

Digests are of the **repo / recipe outputs** (files in the repo tree).
When the meowjre HSP is packed, native libs are **stripped**, so the copies
inside the `.hsp` differ in size and hash (expected, not tampering).
Measured examples: `libjvm.so` 27,707,752 → 22,264,392 B; symtab 64,681 → 0 symbols
(`libc6` / `libjli` / `libjava` likewise). Compare against the repo files.
