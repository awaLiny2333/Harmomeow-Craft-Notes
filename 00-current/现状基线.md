# 现状基线（唯一事实源）

> **身份**：**Harmomeow Craft Launcher**（HarmonyOS 的 *Harmo* + *meow*）；App label = `Harmomeow Craft`；`bundleName` = `meow.liny.craft.awa`。
> **仓库**：`Harmomeow-Craft-Launcher`（启动器源码，`main` 分支）。
> **用途**：本文件是 notes 的**唯一事实源**；任何文档与本文件冲突，一律以本文件为准。
> **维护**：代码合并 / 改名 / 定论变更后，**先改本文件**，再回写其它文档。

## 4. 环境

- SDK `targetSdkVersion`/`compatibleSdkVersion` = **6.1.0(23)**；runtimeOS HarmonyOS；deviceTypes = `["2in1","tablet","phone"]`（设备面；实机目标 = 2in1）。
- 设备实为 **`apiversion=26` / `7.0.0.105`**（比 SDK 新）；MateBook 2in1。
- 开发机 = 运行机；**裸 `hdc` 可用**（`/data/app/bin/hdc`），设备连接键 = `127.0.0.1:$(param get persist.hdc.port)`（`persist.hdc.port`，重启会变勿写死）；部署入口 = `devecocli run`（必要时显式 `--device`），不可用时回退 `hdc app install -r` + `aa start`。
- **agent 的边界**：**可构建**（`devecocli build` 出 HAP / HSP）、**可安装启动**（`devecocli run` 或 `hdc install + aa start`）；
  **不抓日志**（`hilog` / `devecocli log`）、**不操作设备**（代点 UI / force-stop / uninstall / 改设置）；
  **使命终点 = 安装 / 启动完成**，实机表现由拥有者回报。交付 = 代码 + 静态检查 + 验收步骤（`tools/` 下自编件构建脚本同样可跑）。详见 [`工程与规范.md`](工程与规范.md) §二.3「agent 的边界」。
- 部署：**3 个包上机** —— `meowjre` HSP（现代 JRE）+ **`meowjrelegacy` HSP（Java 8 / legacy 那套）** + `entry` HAP（`meowcraftlib`/`meowlwjgls` 是 HAR，编译期静态并入两个 HSP）；构建须点名两个 HSP（`devecocli build --modules entry meowjre meowjrelegacy`）；顺序 = **同版本重装【先 HSP 后 HAP】/ `versionCode` 递增【先 HAP 后 HSP】**（后者否则报 `9568284`）。命令与验证见 [`工程与规范.md`](工程与规范.md) §二 3.1。

## 5. 关键定论（canonical，冲突以此为准；每条按序号称「§5 第 N 条」）

1. **60fps 归因**：= **系统刷新率档位**（"动态" = 60 / "高" = 90），MC FPS 随档位；**不是 MC 自限**（强制 60→90 实验无变化，已证伪）。
2. **渲染后端**：**现代路径（≥1.17）**用系统 `libGLv4.so`（底层 **Mesa 25.0.1 Zink/kopper over Vulkan → Maleoon 916**），**不等价桌面原生 GL**（Zink 有偶发 20–70ms 尖刺）；**legacy（1.6.x–1.12.2）与 ≤1.16.x** 走**自编 `libgl4es.so`**（非 mobileglues）；**MC ≥26.2** 另可在界面选 **Vulkan**（MC 原生后端，经自研 loader shim `libmeowvulkan.so`，失败时 MC 内部回退 GL）——见第 24 条与 [`../20-design/render/渲染链-结论.md`](../20-design/render/渲染链-结论.md) §2。
3. **上屏/合成**：**HWC 直通**（hitrace `DrawImage`=0、`CommitTunnelLayer`）；queue 深度 5；`flush→acquire` avg 8ms(60) / 5.5ms(90)；上屏慢 ≈1 帧。
4. **鼠标输入**：非 grab = 窗口 filter 直通 ~500Hz 绝对坐标（无 delta）；grab = NDK 覆盖节点 `NODE_ON_MOUSE`（`ContentSlot`+`STACK`+`HitTestMode.Transparent`），**采样率 = 显示帧率**（动态 60 / 高 90）。**同一 `ContentSlot` 只能绑一次**。
5. **SurfaceHolder 不迁移**：对延迟/帧率零收益（见 [`../20-design/render/渲染链-结论.md`](../20-design/render/渲染链-结论.md)）。
6. **OpenGTX 关闭**：本机 2in1 无 `RenderAccelerate` syscap / 无 `libopengtx.so`（见 [`../90-archive/渲染迁移评估/05-opengtx-feasibility.md`](../90-archive/渲染迁移评估/05-opengtx-feasibility.md)）。
7. **自研化**：输入 / IME / 关窗 / resize / 独立进程全部自研；**Pojav / Amethyst / HOML 代码已全部清除，无残留**（桥与 GLFW overlay 净室重写并改名 meowcraftbridge）。
8. **版本支持面**：**1.6.x – 26.3**；**均可玩**：1.6.1 / 1.6.4 / 1.7.10 / 1.8.9 / 1.12.2 / 1.16.5 / 1.21.10 / 26.1.2 / 26.2 / 26.3-rc-1。分路径：**1.6.x–1.12.2** legacy LWJGL2 + gl4es（`minecraftArguments` + 自补 `-cp`）；**≤1.16.x** compat profile + 自编 gl4es + 原生 GLES；**1.13–1.21.x 与 ≥1.22** 现代单代 LWJGL 3.4.3（含 3.4.x 兼容 shim）+ OpenAL 1.24.3；**≥26.3** 真 SDL3 fork + `ohos` 驱动。详见 [`版本支持边界.md`](版本支持边界.md)。
9. **LWJGL 世代**：现代**只有一代 3.4.3**（服务 1.13–1.21.x 与 ≥1.22；缺失成员靠 overlay 的 3.4.x 兼容 shim）+ legacy `liblwjgl.so`（LWJGL2，服务 1.6.x–1.12.2）。natives **必须随包**（数据区禁 dlopen），同名以**世代号紧跟基名**消歧 + `bundledLibrary.nameMapper`。
10. **hvigor libs 增删不追踪**：改 `libs/<abi>/*.so`（增或删）后必须清模块 build 再 `devecocli build --modules entry meowjre meowjrelegacy`（`meowlwjgls` 等随包件并入 `meowjre` HSP；不带 `--modules` 只出 HAP、不出 HSP）。
11. **JRE 家族**：**全收编、零黑箱** —— 随包 JRE = **官方 OpenJDK 26.0.2.1（glibc）件原地改 `.dynstr` + 自编 `libc6.so` / `libjli` / `libjvm`**；`libjli`/`libjvm` 打了 `OHOS_DL_DIR` / `OHOS_JAVA_HOME` 分体 patch（源码 + `tools/jre26/patches/`）；**自编件源与官方发布精确对齐**（更新仓 `openjdk/jdk26u` `jdk-26.0.2.1-ga` @ `d55edf1cba61…`，`SOURCE_DATE_EPOCH=1784133400`）⇒ 官方 26 lib / `libc6.so` 不变；**数据 tar 因新增 `jdk.zipfs` best-effort-chmod 补丁类而变**（2026-09-27，见第 27 条）⇒ 数据令牌升 `26.0.2.1+1-7-r2`。BiSheng hnp **不可嵌入**（其 libjli 无 `OHOS_DL_DIR`；见 [`../30-supply-chain/bisheng-hnp-trial.md`](../30-supply-chain/bisheng-hnp-trial.md)）。
12. **音频延迟**：OpenAL 走 **OHAudio**（默认后端），**FAST 已开**（48kHz / S16 / 10ms 回调 / 20ms 缓冲）；`GetLatency()` 系统路由 ≈ **25ms** 为应用层天花板（HAL/硬件），应用侧无可再压（见 [`../40-adaptation/ohaudio-backend.md`](../40-adaptation/ohaudio-backend.md) §9）。
13. **JNA 已摘除**：`libjnidispatch.so` 移除（仅 oshi 用；oshi 改为**合成拓扑**，F3 仍 `20x`）；`jna.jar` 仍来自用户 MC libraries、不在 F3 路径（见 [`../90-archive/supply-chain-retired/jna-analysis.md`](../90-archive/supply-chain-retired/jna-analysis.md)）。

    - **启动侧（外部实例）—— 1.13–1.20.1 已可启动**（2026-09-30 阶段 1 首改）：把"需要真库树的版本"的 classpath 从平铺通配切到**真 maven 树逐条绝对路径 + 实例 jar**（对齐 HMCL 的 `${classpath}`；判据 = 启动形态主类，见 [`../20-design/launch/Forge-1.13及以上-调研与方案.md`](../20-design/launch/Forge-1.13及以上-调研与方案.md) §5.3）。**实测**：**1.16.5（① 代 ModLauncher）已进游戏**（2026-09-30，用户设备）；**1.20.1（② 代 BootstrapLauncher）在真树改动前的平铺下已实测进世界**（真树后待复测；**2026-09-30 用户确认：真树形态下也已跑过**、**日志未导出** ⇒ 该"待复测"以用户确认为准归零）。⇒ 对外部（HMCL / 手动）创建的 **1.13–1.20.1** Forge 实例，**唯一路径 = 被识别并启动**（不含安装）。
    - **范围**：**Forge 支持面截至 1.20.1**（世代 ①+②）；**≥1.20.2 交给 NeoForge**（③ 代 `ForgeBootstrap` = 不在范围内）。**应用内安装已覆盖 1.7–1.20.1**（零 JVM 链 ≤1.12.2 + processor 链 1.13–1.20.1）；外部实例启动 1.13–1.20.1 亦已支持。1.20.2–1.20.4 形态 T0 已补样（②→③ 切点 = 1.20.2→1.20.3；1.20.2 主类已改名，**不写入支持面**）。

29. **键盘：Tab 与 F 行由窗口级按键 filter 接管（native）**：平台对这两类键的**边沿不可靠**（Tab 的 `UP` 从不派发；F 行和弦里固件立刻放掉前键，且键状态也报"已松开"），而**键状态可查**（`OH_Input_GetKeyState`，API 12，无权限）。native 在**应用内部分发之前**消费这两类键并按 GLFW 语义自转发 `press/repeat/release`（其余键一律 `return false`，逐位不变）；释放由一个 tracked 表结算 —— **Tab = 系统状态真值**（松手 ≤16 ms 生效、无约定值）、**F 行 = 和弦 deadline**（`MEOW_FN_CHORD_HOLD_MS = 400 ms`，唯一约定值）；表由**叶锁**保护（filter 回调不在 ArkTS 线程上，实测 5 个 tid），`critical_send_key` 一律在锁外调用；`meow_ring_push` 亦加叶锁（多生产者）。ArkTS 侧原有的整套 F 键绕法（20 ms 延迟释放 / 重复 Down 丢弃 / Up 守卫）**已删除**。**实机验收（用户实机操作，日志复核）**：**26.3 / SDL 上通过** —— 按住 Tab 显示、松手即消失；F3+F4 面板可开、连点可继续循环、停手约 0.4 s 应用；F3 单键与 F3+字母/数字正常；F11 单次切换；导出日志零告警（`KEYFILTER start rc=0`、9 次 `fn chord`、无表满、无 `GetKeyState unavailable`）。**未验**：26.2（GLFW stub）与 legacy（LWJGL2）两代的 Tab / F 行。机制与平台事实见 [`../20-design/input/输入-总览.md`](../20-design/input/输入-总览.md) §2.1、[`已知限制与待解.md`](已知限制与待解.md) §A5/§A9；落地 = `主仓 libs/meowcraftlib/src/main/cpp/meowcraftbridge/input_bridge.c`（内核）/ `.../meowjrebridge/meowjrebridge.cpp`（三个入口）/ `entry/src/main/ets/common/input/GameInputController.ets`（注册 + 16 ms tick）。
