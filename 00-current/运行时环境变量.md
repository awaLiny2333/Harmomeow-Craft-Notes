# 运行时环境变量与调优开关（canonical）

> 定位：本项目启动/游戏进程**应用级（桥 / 启动器 / JVM）运行时环境变量与调优开关**的**唯一清单**：① 用户可填入口 ② 我们（应用/桥）新增的
> `MEOW_*` 开关 ③ 桥内固定 `setenv` ④ 相关 JVM `-D` 入口。**新增/改名/改语义 → 先改本文件**。
> ⚠️ **工具级**开关（由 `Harmomeow-Craft-Launcher/tools/*` 的自编原生件在自己的进程内读）**不并入本表**，权威清单在各 tool README，指针见 **§1.3**。

## 0. 两个「用户可填」入口（零重编 A/B）

高级选项里的两格（落**应用级全局设置** `app-settings.json` 的 `global.runtime` 组，游戏进程启动时读；

| 格 | 格式 | 注入点 |
|---|---|---|

## 1. `MEOW_*` 开关

> 全部走「额外渲染环境变量」；未设置 = no-op。⚠️ **例外**：`MEOW_MALLOC_SLACK*` 与 `MEOW_MASK_EXTENSIONS`
> 是**随包默认开**的规避（不是实验开关）✓。
> **Vulkan 档开关按「默认值」两级一刀切**：**A 级＝功能必需 / 默认开**（不需要用户设置，默认即生效）· **B 级＝诊断 / 默认关**（只在排障时手动打开）。曾有的 **C 级临时探针已整体删除**，不再列示。权威清单 = `meowvulkan.c` 头注释块；原理见 [`../20-design/render/Vulkan后端-实现与原理.md`](../20-design/render/Vulkan后端-实现与原理.md) §3。

### 1.1 能力屏蔽的两个入口（契约）

| 入口 | 影响的层 | 覆盖语义 |
|---|---|---|
| **env `MEOW_MASK_EXTENSIONS`**（「额外渲染环境变量」） | **两层**：LWJGL 能力标志 + Mesa 扩展表（启动器从同一清单派生 `MESA_EXTENSION_OVERRIDE`，仅 `GL_*`） | **整体替换**默认清单（**不是追加**）⇒ 想补一个能力必须把默认的 `GL_ARB_compute_shader` 一起写上；**显式空**（`MEOW_MASK_EXTENSIONS=`）= **两层都关** |
| **`-Dmeow.maskExtensions`**（「额外 JVM 参数」） | **仅 LWJGL 层**（与 env **并集**、只加不减） | 不驱动 Mesa 层（启动器看不到 JVM 属性） |
| 直接写 `MESA_EXTENSION_OVERRIDE` | 仅 Mesa 层 | 用户串拼在我们注入**之后** ⇒ 生效 |
| `-Dmeow.strictCaps` / env `MEOW_STRICT_CAPS` | LWJGL 层（守卫策略）| `1`/`0`；空 = 按渲染路径自动 |

⚠️ 屏蔽**只做"真→假"、不伪造**；它是**规避**（把"驱动崩"换成"能力不可用"，纯性能代价、可一键撤），真解仍在上游驱动。
机制 / 禁止清单 / 四判据 / 边界见 [`../20-design/render/GL能力屏蔽-规范.md`](../20-design/render/GL能力屏蔽-规范.md)（实现在 [`../20-design/render/1.21.1-崩溃-两条链与随包规避.md`](../20-design/render/1.21.1-崩溃-两条链与随包规避.md) §1）。
面向用户的**逐实例开关**：「编辑版本 → **屏蔽 GL_ARB_compute_shader**」（**默认开 = 屏蔽**，与 `MEOW_MASK_EXTENSIONS` 的"设/不设"一致 ✓；关掉 = 用户知情承担崩溃风险），
落在 `versions/<id>/.hmmcraft/instance-settings.json` 的 `hmmcraftComputeShaderMasked`（仅显式 false 才写键，与 glthread 同构），
启动自证行 `computeShader=on(default)/off(user)` ✓。优先级：显式渲染 env > 该开关 > 芯片默认 ✓。

### 1.2 ★覆盖关系：谁盖谁

**一层层往下盖，后写的赢**（`setenv(..., 1)`）：

| # | 谁写的 | 写了什么 | 会被谁盖 |
|---|---|---|---|
| ① | **桥内固定默认**（最低）| `LD_LIBRARY_PATH`/`OHOS_*`/`HOME`/`NGG_DIR_PATH`/`ALSOFT_LOGLEVEL`/`vblank_mode=0`、`GALLIUM_THREAD=0`（基值）、`MEOWCRAFT_RENDERER`（按实例后端）、`MEOWCRAFT_GL_PROFILE`、（gl4es 时 `LIBGL_*` 一串）| ②③④ |
| ② | **逐实例设置**派生的行（启动器拼）| `GALLIUM_THREAD=1/0`（线程化渲染）、`MEOW_GUARD_SYNC=none`（按 MC 版本自动）、`MEOW_MASK_EXTENSIONS` + `MESA_EXTENSION_OVERRIDE`（屏蔽 compute）| ③④ |
| ③ | **「额外渲染环境变量」文本** | 原样逐行（拼在 ② **之后**）| ④ |
| ④ | **GL guard 失效安全**（代码级、最后）| guard 未武装 ⇒ **强制** `GALLIUM_THREAD=0` | **谁都盖不过它** ✗（合理：否则会崩）|

**常见问答 —— 什么情况下哪些逐实例设置会被盖**：

| 你的动作 | 被盖的实例设置 | 结果 |
|---|---|---|
| env 写 `GALLIUM_THREAD=1` | 线程化渲染 | 用你的值 ✓（⚠️ 例外：guard 未武装时仍被 ④ 强制回 0 ✗）|
| env 写 `MEOW_MASK_EXTENSIONS=…` | 屏蔽 compute | **整份替换**默认清单 ⇒ 开关不参与 ✓（想保住 compute 屏蔽就连它一起写 ✓）|
| env 写 `MESA_EXTENSION_OVERRIDE=…` | 屏蔽 compute 的 **Mesa 半边** | 用你的值 ✓（LWJGL 半边不动 ✓）|
| env 写 `MEOWCRAFT_RENDERER=gl4es` | 渲染后端的 **env 部分** | **半覆盖** ⚠️：GL 实现 / GL profile **不看这个 env** ⇒ 真想换后端请在**面板里选** ✓ |
| 「额外 JVM 参数」写 `-Dmeow.maskExtensions=…` | 不盖 env ✓（与 env **并集**、只加不减）| LWJGL 半边 = 属性 ∪ env；Mesa 半边只看 env ✓ |
| 「额外 JVM 参数」写 `-Dmeow.strictCaps=…` | 与 env `MEOW_STRICT_CAPS` 冲突时**属性优先** | 属性赢 ✓ |
| **什么都不写** | — | 全按**逐实例设置 + 芯片默认** ✓ ⇒ 这就是界面上那句「**留空 = 遵守版本实例设置**」✓ |

**与 env 无关的逐实例设置**（别在这格里找它们）：
- **版本隔离** ⇒ 走 bootstraplauncher 的 `runningDirectory` / 进程工作目录 ✓（不是 env ✗）
- **渲染后端的"选哪个实现 + GL profile"** ⇒ 走进程参数（`renderer.lib` / `renderer.glProfile`）；**Vulkan 档**另走 `-Dorg.lwjgl.vulkan.libname=libmeowvulkan.so` + 游戏参数 `--graphicsBackend vulkan` ⇒ **零必配 env** ✓

**一句话记忆**：**面板设置 = 默认值**（我们替你拼好行）→ **env 文本 = 最后说话的人** → **guard 失效安全 = 不许反驳的安全带**（只管线程化那一项）✓

**GL guard（`libmeowglguard.so`）**：作为 LWJGL 的 OpenGL 库（`LaunchDefaults.RENDERER_LIB` → `-Dorg.lwjgl.opengl.libname`，桥预 dlopen 同一名字）。
导出 `glXGetProcAddress`/`ARB`，把绝大多数名字**透传**给系统 `libGLv4.so`，只对**贴图上传家族 8 个入口**返回 wrapper；
另有 15 个同类热路径入口不包、首次解析打点名日志。**gl4es 路径（≤1.16/legacy）不经过它**。回滚 = `RENDERER_LIB` 改回 `RENDERER_LIB_REAL_GL`。

**设备 CPU 拓扑（绑核参考）**：20 核 / 6 簇 —— 小核 `0–3`(cap688)、中核 `4–11`(888)、**大核 `12–19`**(1024/2.316GHz)。

## 3. 与 env/参数相关的关键结论

- **调度类（`MEOW_QOS` + `MEOW_AFFINITY`）无提速收益**：两者生效且无崩，但无可感帧数变化 ⇒ ~8ms/帧固定成本非核心放置问题
  （[`../20-design/perf/QoS与绑核-实验报告.md`](../20-design/perf/QoS与绑核-实验报告.md) §4）。
- **glthread 的 UAF 由 GL guard 补偿**：根因 = `libgallium`/Zink 在 glthread 下访问未映射内存（`tc_texture_subdata` 不拷贝客户端数据、延后 flush 才读）；
  修法 = 对**贴图上传家族 8 个入口**后置同步，并对 ≤1.21.x 关掉该同步（理由见上）。
  上游 bug 报告：[`../20-design/perf/glthread崩溃-Bug报告.md`](../20-design/perf/glthread崩溃-Bug报告.md)；限制条索引：`已知限制与待解.md` §F。
- **回滚阶梯**（glthread 相关异常时，从轻到重）：① 「编辑版本 → 线程化渲染」关掉该版本（`GALLIUM_THREAD=0`，彻底无 UAF）；
  ② 「额外渲染环境变量」写 `MEOW_GUARD_SYNC=flush`（强制每次同步；用户串注入在我们之后 ⇒ 优先）；
  ③ 代码级把 `RENDERER_LIB` 指回 `RENDERER_LIB_REAL_GL`（等于放弃 glthread）。
- **LWJGL 调试开关默认关**：`org.lwjgl.util.Debug`（+`DebugLoader`）与死旗标 `org.lwjgl.opengl.Debug` 已移除；
  排障时用「额外 JVM 参数」`-Dorg.lwjgl.util.Debug=true` 覆盖。
