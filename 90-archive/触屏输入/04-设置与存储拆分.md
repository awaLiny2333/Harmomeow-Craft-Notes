## 0. 形态

- **应用级 8 项**，独立成文件：`<filesDir>/meow-settings/touch-controls.json`。
- JSON 为**扁平**结构 + `format: 1`（仿 `app-settings.json`）。
- 路径常量集中在 `common/constants/Paths.ets`：`MEOW_SETTINGS_DIR` / `TOUCH_CONTROLS_FILE` /
  `BAD_FILE_SUFFIX`，路径函数 `meowSettingsDir(filesDir)` / `touchControlsSettingsPath(filesDir)` /
  `touchControlsBadPath(filesDir)`。
- 底层读写从 `app-settings.json` 的 `current()` / `update()` 切到 `SettingsTools.ets` 的
  `currentTouch()` / `updateTouch()`；**8 组公开 get/set 签名一字未改**。

## 1. 8 个设置项（键名 → 默认 → 钳制）

| JSON 键 | 默认 | 钳制（合法 → 原样；否则回默认） |
|---|---|---|
| `touchAsMouse` | `true` | 布尔；仅显式 `false` 为关，其余（缺失 / 非 false）→ `true` |
| `touchControls` | `false` | 布尔；仅显式 `true` 为开，其余 → `false` |
| `touchSensitivity` | `128` | 正有限数原样；否则 `128`；**上界不限** |
| `touchControlsScale` | `100` | 有限且 >0 → 夹到 `[50, 200]`；否则 `100` |
| `insetTop` | `12` | 有限且 `≥0` 原样；否则 `12`；**上界不限**（0 合法） |
| `insetRight` | `12` | 同上 |
| `insetBottom` | `12` | 同上 |
| `insetLeft` | `12` | 同上 |

- 常量来源：`TOUCH_CONTROLS_DEFAULT`、`TOUCH_SENSITIVITY_DEFAULT_PERCENT`、
  `TOUCH_CONTROLS_SCALE_DEFAULT/MIN/MAX_PERCENT`、`TOUCH_CONTROLS_INSET_DEFAULT`（见 `Constants.ets`）。
- 目标文件示例（首次生成即全部显式写出，便于人工整份替换）：

```json
{
  "format": 1,
  "touchAsMouse": true,
  "touchControls": false,
  "touchSensitivity": 128,
  "touchControlsScale": 100,
  "insetTop": 12,
  "insetRight": 12,
  "insetBottom": 12,
  "insetLeft": 12
}
```

- 数值 / 布尔语义与旧 `global.launcher` 的 normalize **逐字一致**（第 1/2 轮）。
- `touchSensitivity` 的注释口径：**128 = 乘 1.28**（用户实机调出的手感值），**不是**「100 = 正常」。

## 2. 容错（第 3 轮加）

| 情况 | 处理 |
|---|---|
| 文件**不存在 / 空 / 纯空白** | 按缺失：**写出一份完整默认内容**，随后缓存（既有契约） |
| 读到非空内容但 `JSON.parse` 失败 | **判坏** → 先备份成 `<dir>/touch-controls.json.bad`，再用默认并允许写盘 |
| 解析成功但**根不是对象**（null / 数组 / 数字 / 字符串） | **判坏** → 同上 |
| 合法对象但**字段缺失 / 值非法** | **不算坏**：由各 `normalize*` 各自回默认 |

- 备份路径：`touchControlsBadPath(filesDir)` = `touchControlsSettingsPath(filesDir) + BAD_FILE_SUFFIX`（`.bad`）。
- `.bad` 已存在时**直接覆盖**：先删旧 `.bad` 再 `renameSync`，**不做时间戳堆叠**；改名失败被 `try/catch`
  吞掉并记 error，**不影响流程**（继续走默认）。
- 「每次读取最多备份一次」：备份成功后原文件已不在，同轮后续读取不再触发。
- 目的：避免「用户手改打错字 → 之后任意 setter 静默覆盖」的隐患（用户内容已安全躺在 `.bad` 里）。

## 3. 写回规则

- **保留未知字段**：`writeTouchSettings` 先读磁盘现文件解析为底稿，`buildTouchNode` 只覆写 `format` 与
  8 个已知键，**底稿里其余键原样保留**；再 `writeJsonAtomic` 原子写。
- 写入用 `JSON.stringify(obj, null, 2)` 多行缩进，便于手改。
- 文件坏时无结构化未知键可保留，底稿为 `{}`。
- 触控文件也被纳入**导出**（`exportSettings` 由两份扩为三份）。

## 4. 生效时机

- 所有 getter 在**开窗 / 开面板**时读入 ⇒ **开窗生效**（手改文件后重启 / 重开游戏窗生效，当作普通设置看待）。
- **缓存不失效、不做旧值迁移** ⇒ 定案见 [`../../00-current/已知限制与待解.md`](../../00-current/已知限制与待解.md) **§B6**（此处只写指针）。

## 5. 与 native 的接口

- **全部以参数传入 native，无 env**（旧 `MEOW_TOUCH` 环境变量与合成分支**已删**）。
  开关与灵敏度由 ArkTS 经 `touchFilterStart` 的入参控制（native `g_touchEnabled = enable`）。
- 排除区矩形也由 ArkTS 以 CSV 参数传入（见 [03](03-排除区与native桥.md)）。
