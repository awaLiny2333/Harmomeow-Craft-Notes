## 3. 统一 / 修正

- **JRE 类型去重**：`JreLibModule`/`HomlBridgeApi` 唯一化到 `common/state/JvmLauncher.ets`，

## 4. 功能补漏：JRE 未就绪时禁用启动

- 版本区「启动」按钮在 JRE 未解压就绪时 `.enabled(false)`，并显示提示
  （"请先在下方 Java 环境区解压"）——避免无 JRE 的空启动（不做启动时自动解压，保持手动解压语义）。
- 实现：`LauncherState` 新增 `@Trace jreReady` + `refreshJre(filesDir)`；
  JavaEnvView 安装/刷新后与 GameVersionsView 挂载时同步刷新该字段。
